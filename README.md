# BETenio

This repository contains all relevant source code and csv files used for training of BETenio

## src

Contains code for the creation of the AI articles through an LLM running in a local server, processing of the generated articles, stylometric analysis of said articles and a prototype for scraping new articles.

## StylometryResults

Contains the output of the stylometric analysis done on the final dataset's articles

## TrainingData

.7z files containing datasets before processing, after processing and the final Training - Testing splits

## TrainingSrc

Source files for processing datasets and training betenio, alongside outputs generated by stylometric analysis
